# Employee Management System

Dự án Mini Project: **Hệ thống Quản lý Nhân viên (Employee Management System)** được xây dựng theo lộ trình 10 Module Spring Boot:

- **Module 1**: Getting Started with Spring Boot (REST API `/hello`)
- **Module 2**: Custom Bean & IoC (UtilityService, Custom Bean Configuration)
- **Module 3**: REST API cơ bản (CRUD in-memory)
- **Module 4**: Spring Boot + Database (Spring Data JPA, Entity Employee & Department, quan hệ, CRUD DB)
- **Module 5**: Validation & Exception Handling (`@Valid`, Global Exception Handling)
- **Module 6**: Spring Boot Web (MVC + Thymeleaf UI)
- **Module 7**: Logging & Profiles (SLF4J, `dev` và `prod` profiles)
- **Module 8**: Advanced Spring Boot (Actuator, Caching, `@Scheduled` task)
- **Module 9**: Spring Security Basics (User, Role Admin/User, JWT Authentication)
- **Module 10**: Reporting & Analytics (Thống kê theo phòng ban, giao diện `/employees/statistics`)

## Công nghệ sử dụng
- Java 17
- Spring Boot 3.2.5
- Spring Data JPA / Hibernate
- H2 Database (Dev) & MySQL/PostgreSQL (Prod)
- Thymeleaf & Bootstrap UI
- Spring Security & JWT (JSON Web Token)
- Spring Cache & Actuator
